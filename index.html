ASSEMBLY LANGUAGE REFERENCE

8086 Programs

Small, commented examples to help you get started with 8086 arithmetic.

01 · 8-BIT

Addition of two 8-bit numbers

Adds two values and stores the sum and carry.

MOV AL, 25H
MOV BL, 17H
ADD AL, BL
MOV [2000H], AL
MOV BYTE PTR [2001H], 00H
JNC DONE
MOV BYTE PTR [2001H], 01H
DONE: HLT
EXPECTEDAL = 3CH · carry = 0
02 · 8-BIT

Subtraction of two 8-bit numbers

Subtracts the second value from the first; borrow appears in CF.

MOV AL, 35H
MOV BL, 12H
SUB AL, BL
MOV [2000H], AL
MOV BYTE PTR [2001H], 00H
JNC DONE
MOV BYTE PTR [2001H], 01H
DONE: HLT
EXPECTEDAL = 23H · borrow = 0
03 · 16-BIT

Addition of two 16-bit numbers

Adds two words; the carry flag reports overflow beyond 16 bits.

MOV AX, 1234H
MOV BX, 0102H
ADD AX, BX
MOV [2000H], AX
HLT
EXPECTEDAX = 1336H · carry = 0
04 · 8-BIT

Multiplication of two 8-bit numbers

Unsigned MUL multiplies AL by the source and stores the product in AX.

MOV AL, 12H
MOV BL, 04H
MUL BL
MOV [2000H], AX
HLT
EXPECTEDAX = 0048H
05 · 8-BIT

Division of two 8-bit numbers

DIV divides AX by the source; quotient is in AL, remainder in AH.

MOV AX, 0048H
MOV BL, 06H
DIV BL
MOV [2000H], AL
MOV [2001H], AH
HLT
EXPECTEDAL = 0CH · AH = 00H

Examples use hexadecimal immediate values and simple memory locations for illustration. Assemble in the syntax and environment used by your course.

About the lab

Small experiments make big ideas easier to understand.

✿

This project is an interactive learning dashboard for Computer Organization and Architecture. It helps students understand logic gates, truth tables, number systems, complements, and binary addition through visual simulations.

  • Automatic truth tables that follow your inputs
  • Binary conversion and complement tools
  • Half, full, ripple-carry, and CLA adder simulations
  • 8086 arithmetic program examples
